# Button

Buttons trigger an action with a single click: submitting a form, opening a
dialog, confirming or canceling a step. The label says what will happen.

<Canvas of={Stories.Default} />

## Features

- Six variants, from the filled primary to a plain link, in four text sizes and
  four icon sizes.
- Icons marked with `data-icon` pull the padding in on their side.
- Renders as a link, or any other element, through Base UI's `render` prop.
- `destructive` is a red tint, so it never outshouts the primary action.

## Usage

```tsx
import { Button } from "@/components/button"

export function Actions() {
  return (
    <div className="flex gap-2">
      <Button variant="ghost">Cancel</Button>
      <Button>Save changes</Button>
    </div>
  )
}
```

Use one default button per view, and give every other action a quieter
variant.

Button takes every prop of Base UI's `Button`, including `render` for
rendering as a link.
